What is this?

Epsilon is a class-conditional image generator for ImageNet-1K at 64×64, built from scratch on the mathematics of MIT 6.S184 (An Introduction to Flow Matching and Diffusion Models). Generation converts noise into data by simulating a differential equation: samples start at pure Gaussian noise at time \(t=0\) and end at an image at \(t=1\).

The probability path

Training chooses a Gaussian conditional probability path — a gradual interpolation between noise and each data point \(z\):

\[ p_t(x\mid z) = \mathcal{N}\!\big(\alpha_t z,\ \beta_t^2 I_d\big), \qquad \alpha_0 = \beta_1 = 0,\ \ \alpha_1 = \beta_0 = 1, \]

with the CondOT schedulers \(\alpha_t = t\), \(\beta_t = 1-t\). Sampling from the path is just \(x_t = \alpha_t z + \beta_t \varepsilon\) with \(\varepsilon \sim \mathcal{N}(0, I)\).

Velocity field vs. score function

Two equivalent objects describe how probability mass moves along this path:

  • The marginal velocity field \(u_t^{\text{target}}(x)\) defines an ODE \(\mathrm{d}X_t = u_t(X_t)\,\mathrm{d}t\) whose trajectories follow the path — this is a flow model.
  • The marginal score function \(\nabla \log p_t(x)\) is the direction of steepest ascent of log-likelihood — the central object of diffusion models.

For Gaussian paths they are linearly interchangeable (the conversion formula):

\[ u_t^{\text{target}}(x) = a_t \nabla \log p_t(x) + b_t x, \qquad a_t = \beta_t^2 \frac{\dot\alpha_t}{\alpha_t} - \dot\beta_t \beta_t, \quad b_t = \frac{\dot\alpha_t}{\alpha_t}, \]

which is why the toggle above can drive the sampler with either parameterization from the same trained network.

Training: flow matching and score matching

The marginal fields are intractable, but their conditional counterparts have closed forms — and regressing against them minimises the same objective up to a constant. The conditional flow matching loss is

\[ \mathcal{L}_{\text{CFM}}(\theta) = \mathbb{E}_{t,\,z,\,\varepsilon} \big\| u_t^\theta(\alpha_t z + \beta_t \varepsilon) - (\dot\alpha_t z + \dot\beta_t \varepsilon) \big\|^2, \]

and the denoising score matching loss is

\[ \mathcal{L}_{\text{DSM}}(\theta) = \mathbb{E}_{t,\,z,\,\varepsilon} \Big\| s_t^\theta(\alpha_t z + \beta_t \varepsilon) + \tfrac{\varepsilon}{\beta_t} \Big\|^2, \]

with \(t \sim \mathrm{Unif}[0,1]\), \(z\) from the dataset, \(\varepsilon \sim \mathcal{N}(0, I)\). The network that minimises either loss equals the corresponding marginal field.

Sampling: ODE or SDE

Flow matching (ODE) integrates, with e.g. the Euler method,

\[ X_0 \sim \mathcal{N}(0, I), \qquad \mathrm{d}X_t = u_t^\theta(X_t)\,\mathrm{d}t \quad\Rightarrow\quad X_1 \approx \text{image}. \]

Diffusion (SDE) adds Langevin-style noise while preserving the same marginals — valid for any diffusion coefficient \(\sigma_t \ge 0\):

\[ \mathrm{d}X_t = \Big[ u_t^\theta(X_t) + \tfrac{\sigma_t^2}{2} \nabla \log p_t(X_t) \Big]\,\mathrm{d}t + \sigma_t\, \mathrm{d}W_t, \]

simulated with Euler–Maruyama: \(X_{t+h} = X_t + h\,\text{drift} + \sigma_t \sqrt{h}\,\varepsilon\). Setting \(\sigma_t = 0\) recovers the ODE exactly.

Classifier-free guidance

To make samples adhere to the class label \(y\), the model is trained with the label randomly dropped (probability \(\eta\)) so one network learns both the guided field \(u_t^\theta(x|y)\) and the unguided field \(u_t^\theta(x|\varnothing)\). At sampling time they are combined with guidance scale \(w\):

\[ \tilde{u}_t(x\mid y) = (1 - w)\, u_t^\theta(x\mid \varnothing) + w\, u_t^\theta(x\mid y). \]

\(w=1\) is plain conditional sampling; \(w>1\) amplifies the class-dependent component — a heuristic that markedly improves prompt adherence at some cost in diversity.

The full pipeline

  1. Draw noise \(X_0 \sim \mathcal{N}(0, I_{3\cdot 64\cdot 64})\).
  2. Resolve your prompt to an ImageNet class \(y\).
  3. At each of \(n\) steps, evaluate the U-Net/DiT at \((X_t, t, y)\) and \((X_t, t, \varnothing)\), combine with CFG, convert between velocity and score if requested, and take an Euler / Euler–Maruyama step.
  4. Return \(X_1\), mapped from \([-1,1]\) to pixels.
